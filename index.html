Frequently Asked Questions

What is Fhenix?

Fhenix brings confidential computation to onchain applications using fully homomorphic encryption.

What is FHE?

Fully homomorphic encryption lets applications compute on encrypted data without decrypting it first.

How does Fhenix solve blockchain privacy issues?

Applications can keep sensitive inputs and state encrypted while computing on them, and control who can decrypt the results.

What is CoFHE?

CoFHE is the confidential computing infrastructure that helps EVM developers integrate FHE into their applications.

Is Fhenix EVM-compatible?

Fhenix is designed for EVM developers. See the documentation for supported networks and integration instructions.

What’s Fhenix’s relationship with Arbitrum?
